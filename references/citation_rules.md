# 引用规则与领域术语

## 一、引用形式与位置规则
- **顺序编码制**：正文用 `[n]` 或上标 `ⁿ`，按首次出现顺序编号；同一处多引写 `[n, m]` 或 `[n-m]`；文末按编号升序排列。
- **著者—出版年制**：正文 `(作者, 年份)`，多作者按规范省略（等/et al.）；文末按作者姓氏字顺（中文按拼音）排列。
- **脚注制**：正文上标序号，脚注区逐条列出，序号连续。
- **位置规则**：引用紧贴被支撑论断；一句多引就近分别标注或集中于句末编号组；多句共用一个来源时置于共用句末；不得置于图表注或段落末尾充当"万能出处"。

## 二、去重分层判据（详见 method.md）
- L1 DOI 归一后完全一致 → 合并。
- L2 规范化题名 + 首作者 + 年份一致 → 合并。
- L3 题名高相似 + 作者表重合 + 年份相近 → 候选人工确认。
- L4 仅同名作者或仅题名相似 → 禁止自动合并。
- 字段保留优先级：正式版 > 预印本；有 DOI > 无 DOI；信息全 > 信息缺。

## 三、字段映射表（来源格式 → 目标规范）
| 源字段（BibTeX/RIS/EndNote/CNKI） | 目标字段 | 说明 |
|---|---|---|
| `doi` / `DO` | DOI | 大小写与 `https://doi.org/` 前缀归一 |
| `author` / `AU` / `作者` | 作者 | 保留全部作者，按目标规范决定省略规则 |
| `title` / `TI` / `题名` | 题名 | 中英文别名都保留于 `members` |
| `journal` / `JF` / `刊名` | 期刊 | 会议版记会议名，勿混入期刊名 |
| `year` / `PY` / `年份` | 年份 | 在线优先年份与出版年分开记录 |
| `volume` / `VL` / `卷` | 卷 | 缺省保留空，不臆造 |
| `number` / `IS` / `期` | 期 | 同上 |
| `pages` / `SP`-`EP` / `页码` | 页码 | 保留起止页 |
| `booktitle` / `BT` / `会议名` | 论文集/会议 | 与期刊字段互斥，按文献类型取用 |
| `publisher` / `PB` / `出版社` | 出版者 | 专著/学位论文用 |
| `institution` / `学校` | 学位授予单位 | 学位论文用 |
| `type` / 文献类型 | 类型标识 | 按目标规范映射 `[J][M][C][D][S][P][R][N]` |

## 四、文献类型标识（GB/T 7714—2015）
`[M]` 专著、`[J]` 期刊、`[C]` 论文集、`[D]` 学位论文、`[R]` 报告、`[S]` 标准、`[P]` 专利、`[N]` 报纸、`[EB/OL]` 电子文献、`[DB/OL]` 数据库。类型标识缺失时按内容推断并标 `missing_field`，不得凭空指定。

## 五、状态与置信术语
- `verified` / `unverified`：核验是否完成，未完成不等于不存在。
- `match` / `partial` / `mismatch`：论断与来源的匹配程度。
- `needs_source` / `insufficient_evidence`：需来源但缺失 / 证据不足。
- `missing_key` / `missing_field`：主键缺失 / 字段缺失，均不得臆造补齐。
