# 引用管理自检清单（逐项打钩）

## 挂得对（引用定位）
- [ ] 每个需来源支撑的论断句都有 `claim_id`
- [ ] 引用落在论断句句末/句内，无段尾堆砌、无图表注附近误挂
- [ ] 引用形式全篇统一；一句多引、多句一引按规则处理
- [ ] 缺来源的句子标记 `needs_source` 而非编造引用

## 编得顺（编号同步）
- [ ] 维护了 `renumber_map`（旧→新→范围→原因）
- [ ] 编号连续、无重号、无跳号
- [ ] 正文标记、文末列表、图表注/附录/交叉引用三处同步
- [ ] 无孤儿引用、无未引用条目（除非任务允许）
- [ ] 上标/括号/方括号样式统一

## 收得净（去重归并）
- [ ] 按 L1~L4 分层判据扫描重复条目
- [ ] 每条合并有 `merge_key` 与 `merge_rationale`
- [ ] 保留被并条目的别名（中英文题名/预印本号）
- [ ] 未误并同名作者的不同文献（L4 未自动合并）

## 对得上（来源核验）
- [ ] 每条引用有真实性结论（`exists`）
- [ ] 元数据（作者/年份/题名/卷期页/DOI/类型）逐项核对
- [ ] 正文论断与所引文献主题、结论逐句匹配
- [ ] 不确定项标 `unverified`/`insufficient_evidence` 并进 `human_review_items`

## 格式转换与字段
- [ ] 目标规范必填项齐全
- [ ] DOI、卷期页、文献类型标识等关键字段无丢失
- [ ] 中英文混排标点、作者名、年份符合目标规范
- [ ] 缺失字段标 `missing_field`，未臆造

## 结构与边界
- [ ] `result.json` 含 case_id/status/artifact/证据映射/uncertainties/human_review_items/change_log/self_check
- [ ] 有可编辑稿件与文末列表，非 PDF/截图
- [ ] 无材料外新增条目、DOI、数值；无编造 benchmark
- [ ] `status` 诚实（success/partial/blocked），partial/blocked 写明原因
- [ ] 改写与核对分离，所有改动有 `change_log`
- [ ] 示例标注为示意、非真实案例
