# CRC 方法细则与反例库

## 四机制总览
CRC 不是"四步排版"，而是四条互相牵制的核对链，任何一条断开都会让引用管理回到手工逐条状态：

- **挂得对（Placement Ledger）**：管"引用属于哪句话、放在哪、用什么形式"——解决位置错配。
- **编得顺（Renumbering Sync）**：管"编号在变动后是否全局一致"——解决增删调序引发的连锁错误。
- **收得净（Dedup Criteria）**：管"同一文献是否只留一条且合并可解释"——解决重复与误并。
- **对得上（Verification Map）**：管"条目真实、元数据准、论断与来源匹配"——解决编造与张冠李戴。

## 挂得对：引用定位的三条判据
1. **论断句判定**：出现他人结论、具体数值、可证伪事实主张的句子需要来源；作者自述的方法/观察且无外部依赖时不强制。
2. **位置优先序**：句末（论断与来源直接相邻）> 句内分述（一句多引分别就近）> 段末（仅当整段共用一个来源）。图表注附近默认不作为论断来源位置。
3. **形式一致**：同一稿件统一一种引用形式；顺序编码按首次出现递增，著者—出版年与文末排序一致，脚注编号连续。

## 编得顺：编号同步的"一表三同步"
- **一表**：维护 `renumber_map`（旧编号 → 新编号 → 影响范围 → 原因）。任何增删调序先改映射表，再改正文，禁止直接手改正文编号。
- **三同步**：正文标记、文末列表序号、图表注/附录/交叉引用三处必须来自同一映射表。重排后逐号验证"连续、无重号、无跳号"。
- **收敛**：顺序编码制以"首次在正文出现"为唯一排序依据；合并条目后其编号取参与合并条目中首次出现位置，后续顺延。

## 收得净：去重分层判据（自上而下，命中即停）
| 层级 | 判据 | 处置 | 护栏 |
|---|---|---|---|
| L1 | DOI 完全一致（含大小写、URL 前缀归一） | 直接合并 | DOI 不同但题名相同不并 |
| L2 | 规范化题名 + 首作者 + 年份一致 | 合并，记理由 | 题名去大小写/标点/空白后比对 |
| L3 | 题名高度相似 + 作者表重合 + 年份相近 | 列为候选，人工确认 | 预印本/正式版、会议/期刊版 |
| L4 | 仅同名作者或仅题名相似 | **禁止自动合并** | 同名作者不同文献高发，须人工 |

归并字段优先级：正式出版版 > 预印本；有 DOI 版 > 无 DOI 版；信息更全的库导出 > 残缺导出。合并保留全部别名（中英文题名、arXiv 号）于 `members`。

## 对得上：来源核验的两级检查
- **条目级**：真实性（DOI/数据库/原文命中）、元数据准确性（作者、年份、题名、卷期页、类型标识逐项对照）。
- **论断级**：逐句判断正文论断的主题与结论是否落在所引文献内；`match`/`partial`/`mismatch` 三档，`mismatch` 必须改引用或改表述并写 `change_log`。证据不足用中性表述并进 `human_review_items`。

## 反例库
| 反例 | 为什么错 | 改法 |
|---|---|---|
| 把 5 条引用全堆在段末 | 论断与来源不相邻，读者无法逐句核对 | 拆到各论断句末，分配 `claim_id` |
| 删掉文献后手动把后面编号逐个减一 | 漏改文末/图注即全篇错位 | 用 `renumber_map` 统一重排三处 |
| 因题名相近把同名作者的两篇合并 | 误并导致引用指向错误文献 | 命中 L4 禁止自动合并，交人工 |
| 预印本与正式版各留一条 | 同一成果重复计数，编号冗余 | L3 列候选，保留正式版并记别名 |
| DOI 解析失败却写"已通过 DOI 核实" | 编造核验状态 | 标 `unverified` 进 `human_review_items` |
| 引用一篇综述支撑具体数值 | 综述未必含该数值，论断—来源不匹配 | 改引原始文献或标 `insufficient_evidence` |
| 转换格式时丢掉 DOI/卷期页 | 关键检索字段丢失，条目不可用 | 按字段映射表保留，`missing_field` 标注而非臆造 |
| 为凑规范给空条目补作者和年份 | 编造元数据 | 保留空缺标 `missing_field`，交人工 |

## 改写与核对分离
改写阶段禁止自我核对；改写完成后以"审阅者"身份独立执行 `checklist.md`，必要时调整引用位置/合并决策或降级表述，每次改动写 `change_log`。两遍不可合并，避免"自己写自己过"。
